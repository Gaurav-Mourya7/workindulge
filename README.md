# WorkIndulge

A modern, responsive community platform for students, developers, and professionals to build real-world projects with AI assistance.

## Features

- **Landing Page**: Premium SaaS-style landing page with animated hero section
- **User Authentication**: Registration, sign-in, and forgot password functionality
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern UI**: Glass morphism effects, subtle animations, and clean typography
- **Form Validation**: Real-time form validation with error handling
- **OAuth Integration**: Google and GitHub authentication buttons

## Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern CSS with flexbox, grid, and custom properties
- **JavaScript (Vanilla)**: No frameworks, pure JavaScript
- **Bootstrap 5**: UI framework for responsive design
- **Google Fonts**: Instrument Sans and JetBrains Mono fonts

## Getting Started

1. Clone or download this repository
2. Open any HTML file in a web browser
3. Navigate through the pages:
   - Landing page: `landing page/index.html`
   - Registration: `registration/index.html`
   - Sign-in: `signin/index.html`
   - Forgot Password: `signin/forgot password/index.html`

## Pages

### Landing Page
- Hero section with animated elements
- Institution logos showcase
- Statistics bar
- Call-to-action buttons

### Registration Page
- Full name, email, and password fields
- Role selection dropdown

### Sign-in Page
- Email and password fields

### Forgot Password Page

## Design Features

- **Color Palette**: Warm, earthy tones with cream and brown accents
- **Typography**: Instrument Sans for headings, JetBrains Mono for code/labels
- **Animations**: Subtle entrance animations, hover effects, and glass morphism
- **Responsive**: Mobile-first approach with breakpoints at 768px and 992px
- **Accessibility**: Semantic HTML, ARIA labels, and keyboard navigation support

## Custom Components

- **Glass Card**: Frosted glass effect with backdrop blur
- **Custom Select**: Custom-styled dropdown menu
- **Password Toggle**: Show/hide password functionality
- **Toast Notifications**: In-app notification system
- **Page Loader**: Loading overlay with progress bar
